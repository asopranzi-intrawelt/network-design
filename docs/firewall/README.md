# Firewall

Due firewall delimitano la rete: lo USG FLEX 500 in sede e l'OPNsense del datacenter Seeweb, collegati da un tunnel IPsec. La scheda di sede descrive configurazione e piano di revisione; il file `.conf` è il registro delle sole righe toccate da ogni intervento, prima e dopo, e non un dump della configurazione.
